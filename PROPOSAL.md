# Proposal for School Website Development

## 1. Project Overview

We propose to design and develop a modern, responsive and easy-to-manage website for the school.

The website will provide parents, students, teachers and visitors with important school information while giving the school administration a simple system for managing content and receiving school payments through M-Pesa.

The system will be developed using Laravel and the technologies already supported by the existing development environment, without requiring unnecessary new installations.

## 2. Main Website Features

### Public Website

The website will include:

- Home page
- About the School
- School history and background
- Principal/Headteacher's message
- Mission, vision and values
- Academic programmes
- Departments
- School facilities
- Teachers and staff
- News and announcements
- Events
- Gallery
- Contact page
- School location and directions
- Admission information
- Frequently Asked Questions

The website will be fully responsive and accessible on phones, tablets and computers.

## 3. Online Admission

Parents/guardians will be able to:

- View admission requirements
- Download/view admission information
- Submit an admission enquiry/application
- Provide student and parent information
- Receive confirmation of submission

The school administration will be able to view and manage submitted applications.

## 4. M-Pesa Payment Integration

The system will integrate with Safaricom M-Pesa through Daraja. Safaricom describes Daraja as its platform for connecting web and mobile applications to M-Pesa APIs.

Parents/guardians will be able to:

- Enter the student's admission/registration number
- Select the payment type
- Enter the amount
- Enter their M-Pesa phone number
- Receive an M-Pesa payment prompt
- Complete payment from their phone
- Receive payment confirmation

Possible payment categories include:

- School fees
- Admission fees
- Registration fees
- Transport fees
- Meals
- Other school charges

The administration dashboard will show:

- Payment amount
- Student
- Parent/guardian
- Payment reference
- M-Pesa transaction number
- Payment status
- Date and time
- Outstanding balance

## 5. School Administration Dashboard

A secure administration area will allow authorized staff to manage the website.

### Dashboard

Administrators will see:

- Total students/applications
- Recent payments
- Total payments received
- Pending payments
- Recent enquiries
- Upcoming events
- Recent announcements

### Content Management

Administrators can manage:

- News
- Announcements
- Events
- Gallery
- Staff
- Academic programmes
- Facilities
- Admission information
- Contact information

This means the school will not need a developer every time it wants to update ordinary website information.

## 6. Student and Parent Records

The system can maintain basic records for:

- Students
- Parents/guardians
- Classes
- Admission numbers
- Fee information
- Payment history

Parents can use the student's admission/registration number when making payments.

## 7. Reports

The administration will be able to view and generate reports such as:

- Daily payments
- Monthly payments
- Student payment history
- Outstanding balances
- Admission applications
- Payment summaries

## 8. Security

The system will include:

- Secure administrator login
- User roles and permissions
- Protected administrative pages
- Form validation
- Secure payment processing
- Database protection
- Activity/audit records where applicable
- Secure handling of M-Pesa credentials

## 9. Technology

The project will use the existing supported development environment, primarily:

- Laravel
- PHP
- MySQL/database already supported by the environment
- Blade/HTML/CSS/JavaScript
- Existing frontend tooling
- Laravel authentication and authorization
- M-Pesa Daraja API

No unnecessary framework or package migration will be introduced.

Where an existing supported component can perform a function, it will be reused instead of installing another technology.

## 10. Deliverables

The completed project will provide:

1. Professional school website
2. Responsive mobile-friendly design
3. School administration dashboard
4. Content management
5. Online admission/enquiry system
6. Student/parent records
7. M-Pesa payment integration
8. Payment tracking
9. Payment reports
10. News and announcements
11. Events management
12. Gallery management
13. Contact/enquiry management
14. Secure administrator access
15. Basic documentation and handover

## 11. Development Approach

The project will be developed in stages:

### Phase 1 – Website

- Design
- Pages
- Navigation
- School content

### Phase 2 – Administration

- Admin login
- Dashboard
- Content management
- Student/application management

### Phase 3 – Payments

- M-Pesa integration
- Payment records
- Payment confirmation
- Payment reports

### Phase 4 – Testing & Deployment

- Functional testing
- Mobile testing
- Security checks
- M-Pesa testing
- Deployment
- Administrator training

## 12. Important Note

The project will prioritize using the existing system and installed technologies. No unnecessary new installations will be required.

The M-Pesa connection will use Safaricom's official Daraja platform and its available APIs.

## 13. Conclusion

The proposed school website will provide the school with a professional online presence while also introducing useful digital services such as online admissions, administration, student records and M-Pesa payments.

The system will be designed to remain simple for school staff to operate and flexible enough to expand later as the school's requirements grow.
